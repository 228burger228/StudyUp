### Этап 3: Профили пользователей — Апрель 2024
**Цель:** Студенты и преподаватели имеют персональные профили

#### Для студентов:
- [ ] Личный кабинет
- [ ] Просмотр купленных курсов
- [ ] История обучения
- [ ] Успеваемость
- [ ] Загруженные задания

#### Для преподавателей:
- [ ] Страница преподавателя
- [ ] Список студентов
- [ ] Проверка домашек
- [ ] Расписание занятий
- [ ] Статистика

#### API endpoints:
```
GET  /api/profile/me           # Мой профиль
PUT  /api/profile/me           # Обновить профиль
POST /api/profile/avatar       # Загрузить аватар
GET  /api/users/:id            # Профиль пользователя
```

### Этап 4: Функционал учеников — Май 2024
**Цель:** Студенты могут загружать домашки и смотреть записи

#### Задачи:
- [ ] Загрузка домашних заданий
- [ ] Система проверки статуса
- [ ] История пройденных уроков
- [ ] Просмотр видеозаписей
- [ ] Скачивание материалов
- [ ] Оценки и отметки

#### API endpoints:
```
POST   /api/homework/:courseId/upload    # Загрузить домашку
GET    /api/homework/:courseId           # Список домашек
PUT    /api/homework/:id/status          # Отметить пройденным
GET    /api/lessons/:courseId            # История уроков
GET    /api/lessons/:id/video            # Видео запись
GET    /api/materials/:courseId          # Материалы курса
```

## 📊 Ресурсы

### Разработка

| Роль | Задачи | Этапы |
|------|--------|-------|
| **Frontend** | UI/UX, JavaScript | 1-6 |
| **Backend** | API, БД, логика | 2-6 |
| **DevOps** | Деплой, сервера | 3+ |
| **QA** | Тестирование | 2+ |

### Технологии

```
Frontend:
- React 18+
- Tailwind CSS или Ant Design
- Axios для API

Backend:
- Node.js + Express
- PostgreSQL 13+
- Redis для кеша
- Socket.io для чата
- JWT для авторизации

Инфраструктура:
- Docker
- GitHub Actions (CI/CD)
- AWS/Digital Ocean/Heroku
```
