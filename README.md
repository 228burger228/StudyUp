# STUDY UP — Онлайн-школа

Современная платформа для онлайн-обучения с полноценным функционалом для студентов и преподавателей.

## 📋 Статус проекта

**Этап:** MVP (Минимально жизнеспособный продукт)

### ✅ Завершено
- Основной UI/UX дизайн (главная страница)
- Полноэкранное меню навигации
- Интерактивные факты о школе
- Карусель преподавателей
- Каталог курсов
- FAQ раздел
- Адаптивный дизайн
- Тест на подбор предмета

### 🔄 В разработке
- [ ] Система профилей пользователей
- [ ] Загрузка домашних заданий
- [ ] История пройденных уроков
- [ ] Просмотр записей уроков
- [ ] Личный кабинет студента

### 📅 Планируется
- [ ] Оплата и подписки
- [ ] Система уведомлений
- [ ] Чат с преподавателями
- [ ] Дипломы и сертификаты
- [ ] Рейтинговая система

## 🛠 Технологический стек

### Frontend
- **HTML5** — структура
- **CSS3** — стилизация (Montserrat, градиенты, флекс/грид)
- **Vanilla JavaScript** — интерактивность

### Design
- Figma макеты
- Фиолетовые, оранжевые, жёлтые градиенты
- Glassmorphism эффекты

### Backend (будущее)
- Node.js + Express
- PostgreSQL
- Redis (кеш)
